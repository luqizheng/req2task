# ProjectDetailView 需求列表功能规格说明

## 1. 功能概述

在 ProjectDetailView 的产品视图中实现需求列表展示和创建需求功能，支持查看、筛选、创建需求。

## 2. 用户场景

**目标用户**: 产品经理、需求分析师

**使用场景**:
- 产品经理在项目详情页面快速查看项目下的所有需求
- 产品经理直接创建新需求，无需跳转到单独的页面
- 按状态、优先级筛选需求

## 3. 功能需求

### 3.1 需求列表展示

**核心功能**:
- 展示当前项目的所有需求列表
- 支持分页加载（默认每页 10 条）
- 显示字段：标题、优先级、状态、故事点、用户故事数、创建时间
- 点击需求标题跳转至需求详情页

**筛选功能**:
- 按状态筛选（草稿、已评审、已批准、已拒绝、进行中、已完成、已取消）
- 按优先级筛选（紧急、高、中、低）

**交互行为**:
- 列表加载时显示 loading 状态
- 空列表时显示空状态提示和"新建需求"按钮

### 3.2 创建需求

**触发方式**:
- 点击"新建需求"按钮

**表单字段**:
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 需求标题 | 文本输入 | 是 | 最大长度 200 字符 |
| 所属模块 | 下拉选择 | 否 | 从项目模块树中选择，支持多选 |
| 描述 | 多行文本 | 否 | 需求详细描述 |
| 优先级 | 下拉选择 | 否 | 默认"中"，选项：紧急/高/中/低 |

**验证规则**:
- 标题必填，1-200 字符
- 描述最大长度 2000 字符

**提交行为**:
- 创建成功后关闭对话框
- 自动刷新列表
- 显示成功提示

**错误处理**:
- 显示后端返回的错误信息
- 网络错误显示通用错误提示

### 3.3 查看需求详情

**交互行为**:
- 点击需求标题或详情按钮跳转到 RequirementDetailView
- 路由路径: `/requirements/{id}`

## 4. 技术实现

### 4.1 组件结构

```
ProjectDetailView.vue
├── 产品视图卡片
│   ├── 列表头部（标题 + 新建按钮）
│   ├── 筛选表单
│   ├── 需求表格
│   └── 分页组件
└── 创建需求对话框
    └── 表单（标题、模块选择、描述、优先级）
```

### 4.2 状态管理

使用现有的 `useRequirementStore`:
- `fetchRequirementList(moduleId, params)` - 获取需求列表
- `createRequirement(moduleId, data)` - 创建需求
- `requirementList` - 需求列表数据
- `total` - 总数
- `loading` - 加载状态

### 4.3 API 调用

使用现有的 `requirementsApi`:
- `getListByProject(projectId, params)` - 按项目获取需求列表
- `create(moduleId, data)` - 创建需求

### 4.4 依赖模块选择

使用 `featureModulesApi.getTree(projectId)` 获取项目模块树数据。

## 5. UI/UX 设计

### 5.1 布局

- 产品视图卡片占满主内容区域
- 表格宽度 100%
- 分页组件右对齐
- 创建对话框宽度 500px

### 5.2 样式

沿用现有设计风格：
- 卡片圆角: 8px
- 按钮样式: 使用 Element Plus 组件
- 标签样式: 使用 Element Plus Tag 组件

### 5.3 状态样式

**优先级标签**:
- 紧急: type="danger"
- 高: type="warning"
- 中: type="primary"
- 低: type="info"

**状态标签**:
- 草稿: type="info"
- 已评审: 无色
- 已批准: type="success"
- 已拒绝: type="danger"
- 进行中: type="warning"
- 已完成: type="success"
- 已取消: type="info"

## 6. 路由

**跳转到需求详情**:
- 路径: `/requirements/:id`
- 参数: id - 需求 ID

## 7. 边界情况

### 7.1 空状态
- 无需求时显示空状态卡片
- 提供"新建需求"和"AI 生成需求"两个入口

### 7.2 加载状态
- 列表加载时显示骨架屏或 loading 动画

### 7.3 错误状态
- 网络错误时显示错误提示
- 提供重试机制

### 7.4 表单验证
- 标题为空时阻止提交
- 显示实时验证反馈
