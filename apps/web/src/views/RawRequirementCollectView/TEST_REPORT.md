## 发现的问题

### 1. AI 对话 API 404 错误（待重启验证）

**问题描述**: 消息发送后 AI 响应失败，错误信息：`Error: HTTP error! status: 404`

**测试步骤**:

1. 在 AI 对话输入框输入：`用户登录系统时需要支持手机号验证码登录`
2. 点击发送按钮
3. 消息发送成功（显示在对话中）
4. AI 响应失败，显示 "发送失败"

**根因分析**:

- 前端 `llm-config.ts` 中 `AI_CHAT_BASE` 配置可能仍有问题
- 或 Vite 代理配置 `/api/chat` 未生效

**修复方案**:

1. 检查 `apps/web/src/config/llm-config.ts` 中的 API 配置
2. 确认 `vite.config.ts` 中的代理配置是否正确
3. 重启前端服务（`pnpm dev:web`）使配置生效

**控制台日志**:

```
Failed to load resource: the server responded with a status of 404 (Not Found)
```
